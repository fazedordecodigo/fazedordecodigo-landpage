# Fazedor de Codigo - Brand Assets

Primeira identidade visual vetorial para a comunidade Fazedor de Codigo.

## Conceito

**Oficina Viva**: uma identidade de comunidade brasileira para quem constroi software de verdade com IA, cloud e engenharia pratica.

O simbolo combina:

- um **F modular**, construido como bloco de interface;
- uma **barra de codigo** em azul cloud;
- um **prompt/chevron** em laranja ferramenta;
- um pequeno marcador verde de deploy;
- um ponto amarelo que funciona como sinal, acento e energia de encontro.

## Arquivos

- `logo-symbol.svg`: simbolo principal.
- `logo-horizontal.svg`: lockup horizontal para site, deck e header.
- `logo-stacked.svg`: lockup vertical para capas e cartazes.
- `avatar.svg`: versao escura para redes sociais.
- `favicon.svg`: icone pequeno.
- `badge-demo-slide.svg`: selo de campanha/evento.
- `social-card.svg`: card para compartilhamento social.
- `tokens.css`: tokens e classes base da identidade.
- `brand-board.html`: quadro visual para revisar a identidade.

## Uso recomendado

- Use `logo-horizontal.svg` em headers e materiais institucionais.
- Use `avatar.svg` em redes sociais.
- Use `logo-stacked.svg` em capas, posters e slides.
- Use `badge-demo-slide.svg` como selo em posts de eventos praticos.
- Use `social-card.svg` como base para Open Graph ou posts.

## Cuidados

- Esta e uma primeira versao vetorial, nao uma marca registrada.
- Antes de uso publico amplo, faca teste de reducao, contraste, impressao e revisao juridica/trademark.
- Evite aplicar gradientes roxo/azul, robo, cerebro digital ou nuvem literal como marca principal.
